ReviewHopper

Ouvre le fichier et la ligne d'un diff GitHub dans l'éditeur local.

Utilisation
  • Onglet Files changed d'une PR ou page de commit : survoler une ligne puis cliquer sur ↗, ou ⌥+clic sur la ligne.
  • Onglet Conversation : même chose sur l'extrait de code d'un commentaire ; ⌥+clic sur le nom du fichier ouvre la ligne commentée ; le bouton de copie à côté copie le chemin du fichier (à coller dans la recherche de fichiers de l'éditeur).
  • ⌥+clic sur le nom d'un fichier dans le diff : ouvre le fichier à la ligne 1.

1Éditeur

Ouverture via le lien idea://open enregistré par l'IDE (le lancer une fois après son installation). Au premier clic, le navigateur demande l'autorisation d'ouvrir l'application : cocher "Toujours autoriser". Le dossier local du dépôt est indispensable (étape 2).
Xcode n'a pas de lien pour ouvrir un fichier à une ligne : installer une fois la petite app relais ReviewHopper Xcode (dans ~/Applications), qui lance xed --line. Dans un terminal (Homebrew) :
brew install --cask jean-melikian/tap/reviewhopper-xcode
Au premier clic, le navigateur demande l'autorisation d'ouvrir l'application : cocher "Toujours autoriser". Le dossier local du dépôt est indispensable (étape 2). Pour vérifier : la zone "Tester" doit ouvrir Xcode à la bonne ligne. Désinstaller : brew uninstall --cask reviewhopper-xcode. Sans Homebrew : voir le README.
Avec un dossier local : lien idea://open. Sans dossier : serveur intégré de l'IDE (Settings › Tools › Web Browsers and Preview › Built-in Server, cocher Allow unsigned requests).
Variables : {abs} {absUri} {absEnc} {rel} {root} {line} {line0} (à partir de 0) {col} {owner} {repo}. Une URL http://localhost… est appelée en arrière-plan au lieu d'être ouverte.

2Emplacement des dépôts

Où se trouvent les clones locaux. Les dépôts listés ici passent avant le dossier par défaut.

Dépôt GitHub
Dossier local
Dépôt : owner/repo ou repo. Dossier : chemin absolu (~ accepté si le dossier personnel est connu, voir plus bas).
{owner} et {repo} sont remplacés ; sans variable, le nom du dépôt est ajouté à la fin.
Dossier personnel (pour ~)
Remplace un ~ en début de chemin. Rempli automatiquement si un chemin absolu sous /Users/<nom> est saisi.

3Tester

Coller une URL GitHub (PR, commit, fichier) ou un chemin owner/repo/chemin/du/fichier.
